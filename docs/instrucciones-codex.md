# Cómo trabajar con Codex
1. Abre la carpeta raíz del proyecto.
2. Pide primero: «Revisa README.md, AGENTS.md y docs/. Analiza la Fase 0 sin modificar archivos. Resume riesgos y estado.»
3. Luego solicita una fase concreta, por ejemplo: «Implementa únicamente la Fase 1 según docs/fases-desarrollo.md. Antes presenta un plan y espera mi aprobación.»
4. Pide siempre verificación, listado de archivos y explicación de cambios.
5. No pegues secretos en el chat ni los incluyas en commits.
